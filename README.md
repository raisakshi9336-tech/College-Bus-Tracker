# 🚌 College Bus Tracker

A web-based college bus tracking system developed using HTML, CSS, JavaScript and Firebase.

## 📌 About the Project

College Bus Tracker helps students check bus information and status.
Drivers can update bus details, and students can view the latest updates through the website.

## ✨ Features

- Student Dashboard
- Driver Dashboard
- Admin Dashboard
- Bus Status Updates
- Firebase Realtime Database Integration
- Responsive User Interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Firebase Realtime Database

## 🎯 Project Objective

The main objective of this project is to make college bus information easily accessible to students and improve communication between drivers and students.

## 👩‍💻 Project Type

Web-Based Application

## 🚀 Future Improvements

- GPS-based live bus tracking
- Estimated arrival time
- More bus routes and stops
